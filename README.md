# Sistema de Gestão de uma Loja Online

## Sobre o projeto

Este é um projeto acadêmico desenvolvido na disciplina de Modelagem de Banco de Dados.

O objetivo é planejar um sistema de gestão para uma loja online, organizando informações de clientes, produtos, vendas e estoque.

## Objetivos

- Gerenciar o cadastro de clientes.
- Controlar produtos e estoque.
- Registrar vendas e acompanhar pedidos.
- Organizar as informações em um banco de dados.

## Entidades identificadas

- Cliente
- Produto
- Venda
- Pedido
- Estoque

## Tecnologias e conhecimentos

- Modelagem de Banco de Dados
- Organização de dados
- Identificação de entidades e processos
- Dados estruturados e não estruturados

## Tipo de projeto

Projeto acadêmico — Experiência prática 1.
